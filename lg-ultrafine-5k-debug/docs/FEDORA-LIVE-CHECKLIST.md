# Fedora GNOME comparison

Use the repository's `../../framework-lg-ultrafine-5k-investigation.md` as the full brief. This checklist does not authorize installation, firmware changes, or changes to NixOS. Current comparison baseline: LG through the **left-rear USB-C expansion module**, original LG cable, separate laptop charger disconnected. The 10 October NixOS snapshot after shutdown is `../evidence/20261010T122735-left-rear-module-after-shutdown-Kstoz1/`. Do not use the unverified direct-mainboard connection.

1. Use an official, verified stable [Fedora Workstation x86_64 Live image](https://fedoraproject.org/workstation/download/). Record its exact release and checksum. The owner creates the USB on a disposable drive and boots it manually with F12. Before reboot, arrange transfer of this checklist and `scripts/collect.sh` / `scripts/trace.sh` to the live session, plus somewhere to save evidence afterward. Creating installer media erases its target: identify and confirm that device before writing it.
2. Keep the internal SSD untouched, lid open, and internal panel enabled. Select the live session, not installation.
3. Start with the LG disconnected. Record `uname -r`, `/etc/os-release`, GNOME/Mutter versions, and Wayland session type. Run `bash scripts/collect.sh fedora-disconnected` from a copy of this investigation directory on separate writable media.
4. Start `bash scripts/trace.sh fedora-left-rear 180`. Use the **same cable, left-rear port and installed USB-C module** as the latest NixOS run; separate charger remains disconnected. Connect the LG after capture starts; wait 60 seconds. Record the insertion time and where the Live USB is connected. If trace kernel access is denied, preserve the full root-readable journal in step 5.
5. Run `bash scripts/collect.sh fedora-left-rear-connected`. Hyprland commands being unavailable is expected; no Nix tools are needed in Fedora. If the kernel journal requires root, save it separately with `sudo journalctl -k -b --no-pager -o short-monotonic > kernel-root.txt` in that snapshot's evidence folder. Save `gnome-shell --version`, `rpm -q kernel-core mutter mesa-dri-drivers`, and `printf '%s\n' "$XDG_SESSION_TYPE"` there too. Missing optional diagnostic tools are not evidence of missing hardware.
6. Photograph the physical display and GNOME Settings → Displays. Record whether a single native 5120×2880@60 monitor is offered, whether it actually lights, and whether eDP remains working. Capture DRM TILE properties and binary EDIDs if available.
7. Preserve this first comparison before considering another port. A rear-right repeat is optional only if the result gives a reason to test it; do not combine it with the initial OS comparison.
8. Save evidence on a second USB or approved network destination before shutdown: live-session home storage is ephemeral. Reboot into NixOS after removing the Live USB.

A working Fedora result changes kernel and userspace together; compare enumeration and versions before blaming Hyprland. A black display with no external TB router keeps USB4 negotiation as the priority.
